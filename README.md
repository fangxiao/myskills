# 🚀 Claude Code 开源技能合集 (Claude Skills Hub)

精选实战级 Claude Code & AI Agent 技能合集，支持一行命令安装，开箱即用。

---

## 📦 技能列表 (Skill Matrix)

| Skill 名称 | 核心功能 | 典型使用场景 |
| :--- | :--- | :--- |
| **`quick-site-builder`** | **3分钟极速建站** | 零成本、免备案一键生成现代化 SPA 独立知识库与博客 |
| **`independent-knowledge-base-publisher`** | **知识库全流程发布与 SEO** | GitHub + Cloudflare Pages 边缘分发，百度/谷歌 SEO 自动收录与流量分析 |
| **`wechat-official-account`** | **微信公众号 100% 保真排版** | 纯行内 CSS、OneDark 代码语法染色、全选即拷，解决样式丢失痛点 |
| **`baoyu-skills`** | **宝玉自媒体去 AI 味与矩阵分发** | 自然语言重写、生活化比喻、小红书/微博/公众号多平台图文切片 |

## ⚡ 一键安装 (Quick Install)

在任意 macOS / Linux 终端中运行下方一行命令即可完成安装：

```bash
curl -fsSL https://raw.githubusercontent.com/fangxiao/claude-skills/main/install.sh | bash
```

---

## 💻 使用方法 (Usage in Claude Code)

打开终端运行 `claude` 进入 Claude Code 交互：

```bash
# 1. 快速建站
> 用 quick-site-builder 帮我在 ./my-docs 目录搭建一个独立知识库

# 2. 公众号排版
> 用 wechat-official-account 帮我把这篇 Markdown 转成公众号专用保真 HTML

# 3. 百度/谷歌 SEO
> 用 independent-knowledge-base-publisher 帮我更新 sitemap 并推送到百度 API
```
